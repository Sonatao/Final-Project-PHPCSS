The purpose of the project beyond the grade is to build an e-commerce website front to back, with auto populating store pages, proper styling of content on the pages to create a coherent look, with consistent branding colors, as well as an inviting 
feeling it all, though before all of this, being very easy to navigate and follow.

The idea for this is a Halloween Shop! That is going to be the theme of this particular E-Commerce Website, the colors, branding and wording will be consistent with that.

Aside from front end population, the backend will also handle different views.
One for Guests, who, will be able to see the number of products left, the product price, product name, product description and the specifics, but can only have access to creating an account, favoriting it into a seperate favorites table populated to each specific user
which then appearing on a seperate favorites page, and adding to cart, however, this project will not have Strip integration for payment systems as that is not within the scope of the project.

The other client level will be Admin. They will have the ability to create, read, update and delete items off the database through an interface, aka, another page which can only be accessed through admin view, there they will find the tools to navigate the 
database and do whatever it is they need to do in order to change items prices, names or anything within the Product Table of the Database. 

Measuring success will be in how user friendly the front end is while maintaining consistent branding and colors, as well as, how secure the backend is and how well the CRUD works to satisfy the requirements of it's abilities, such that even someone with no
knowledge of databases and use it effectively.

These are my deliverables and my scope for this project.
